How to run it locally
Since the app doesn’t have a backend or database you shouldn’t have any problems running this code. This application uses standard web technologies (HTML, CSS and JavaScript). You can run it in any modern web browser (Chrome, Firefox or Edge). To begin you’ll need to run git clone https://github.com/vita1288/responsive-dashboard.git .

Once you have downloaded the repository, you can go to dashboard directory. cd dashboard. Now you can open the index.html file in your favorite web browser. If you are using Visual Studio Code then you can install the Live Server extension and open the file with it.
