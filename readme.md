<h1>Responsive Admin Dashboard 📊</h1>
<p>
  This responsive admin dashboard is built with a clean, modern design and is easy to use on any device. 
  It is coded using standard HTML, CSS, and JavaScript, with a fintech-inspired color palette featuring light gray, white, and emerald.
</p>
<hr>
<h2>What's Included</h2>
<ul>
  <li>✅ Responsive layout optimized for mobile, tablet, and desktop screens.</li>
  <li>📱 Collapsible sidebar for mobile devices.</li>
  <li>📌 Fixed header pinned to the top of the viewport.</li>
  <li>📊 Data table featuring built-in pagination and real-time search filtering.</li>
  <li>🔄 Comprehensive UI states: Demo Data, Loading, Error, Empty States, and Recent Feeds.</li>
  <li>⚡ Pure Vanilla JavaScript — zero heavy external JS frameworks needed. Tailwind CSS loaded via CDN.</li>
</ul>
<hr>
<h2>Tech Stack</h2>
<ul>
  <li><strong>Markup:</strong> HTML5</li>
  <li><strong>Styling:</strong> Tailwind CSS (via CDN)</li>
  <li><strong>Logic:</strong> Vanilla JavaScript (ES6+)</li>
  <li><strong>Icons:</strong> Lucide / Phosphor Icons</li>
</ul>
<hr>
<h2>How to Run Locally</h2>
<p>
  Since the application is entirely client-side without any backend or database dependencies, it runs out of the box in any modern web browser (Chrome, Firefox, Edge, or Safari).
</p>
<h3>1. Clone the Repository</h3>
<pre><code>git clone https://github.com/vita1288/responsive-dashboard.git</code></pre>
<h3>2. Open the Project</h3>
<p>Navigate into the directory:</p>
<pre><code>cd responsive-dashboard</code></pre>
<p>
  Open <code>index.html</code> directly in your web browser, or launch it using the 
  <strong>Live Server</strong> extension in Visual Studio Code.
</p>
