# Responsive Admin Dashboard Dashboard 📊
This responsive admin dashboard is built with a clean and modern design and is easy to use on any device. It is coded in HTML, CSS, and JavaScript. It has similar colors to fintech apps such as light gray, white, and emerald.

## What's included

- ✅ Responsive design works on tablets and computers
- 📱 Sidebar collapsing on mobile devices.
- Header stays at the top
- Table with pagination and searching
- Demo Data, Loading, Error, Empty States, Recent Feeds, and many more.
- All code is written in Vanilla JavaScript no external libraries needed. Only Tailwind CSS is used via CDN.

## Tech stack
- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Phosphor Icons / Lucide

## How to run it locally
Because the app doesn't have a backend or database, you should have no problem running this code. This application uses standard web technologies like HTML, CSS, and JavaScript. You can run this app in any modern web browser like Chrome, Firefox, or Edge.
To begin, you'll need to run
git clone https://github.com/vita1288/responsive-dashboard.git

After downloading the repository, you can navigate to the dashboard directory.
cd dashboard
Then you can open the index.html file in your favorite web browser.
If you are using Visual Studio Code you can install the Live Server extension and open the file with it.
